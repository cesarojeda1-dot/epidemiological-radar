# 🐕 LexiPet Sentinel — Ecosistema B2B2C Global

Plataforma de bioseguridad veterinaria, teleconsulta, farmacia, seguros y radar epidemiológico.

## 🚀 Instalación Rápida

### Frontend (React + Vite + TypeScript)

```bash
cd frontend
npm install
npm run dev
```

Accede a: **http://localhost:5173**

### Backend (Node.js + Express)

```bash
cd backend
npm install
npm run dev
```

Servidor en: **http://localhost:3001**

## 🎯 Módulos

- ✅ **Dashboard** — KPIs en tiempo real
- ✅ **Farmacia** — Catálogo con carrito

- ✅ **Teleconsulta** — Médicos en línea

## 🔧 Tecnología

- **Frontend:** React 18 + TypeScript + Vite + TanStack Query
- **Backend:** Node.js + Express + TypeScript
- **State:** Zustand
- **UI:** CSS moderno (sin frameworks pesados)
